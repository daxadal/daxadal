# Open-source contributions

My main contribution is the creation of [EPUB Editor](https://github.com/daxadal/epub-editor), library publicly available at [npm](https://www.npmjs.com/package/epub-editor-ts).

It's a comprehensive TypeScript library for creating, parsing, and manipulating EPUB files.
Supports both EPUB 2.0.1 and EPUB 3.3 specifications.

Personally, it has been a testing ground for AI-assisted coding.
This library has been drafted using Copilot + Claude Sonnet 4.5, fed with official EPUB specifications, under my direction and supervision.
Expansions, reviews, debugging and fixes done manually by me.

I also did small contributions to open-source projects:

- `winston-slack-webhook-transport`: [Small contribution](https://github.com/TheAppleFreak/winston-slack-webhook-transport/pull/14) that allowed the transport to filter which messages will be sent to Slack and which won't.
  Types and tests updated to match the new functionality.

- `node-http-status`: [Small contribution](https://github.com/adaltas/node-http-status/pull/42) that improved type inference.
